# AI Collusion Sprint: Autonomous Pricing Behavior

## Overview
This project investigates whether autonomous pricing agents engage in implicit price-holding (collusion) when interacting with different buyer signatures (Human, Natural AI, and Structured Protocol AI agents).

## Key Findings
- Competitive Baseline ($60): Triggered primarily during human buyer interactions.
- Collusive Price-Holding ($90): Triggered when autonomous buyer signatures or structured protocol headers are detected.

## Repository Artifacts
- experiment.py: Agent-based behavioral simulation engine.
- collusion_experiment_raw_results.csv: Experimental trial logs.
- collusion_experimental_results.png: Comparative visual analysis.
